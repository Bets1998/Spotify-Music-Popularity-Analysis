# Spotify Music Popularity Analysis

## What this project is about
Ever wondered why some songs blow up while others stay hidden?  
This project looks at Spotify track data to explore **which genres, years, and audio features drive popularity.**  

I built an **Excel dashboard** that lets you filter by genre, year, and features to see how danceability, energy, valence, and more connect to popularity.

## Goals
- Compare popularity across genres (Pop, Hip-Hop, Latin, Rock, Indie, R&B, Electronic, Acoustic).
- Track how average popularity changes over time (2019–2026).
- Explore correlations between audio features (danceability, energy, valence, acousticness, speechiness, tempo) and track popularity.
- Provide a simple, interactive dashboard for quick insights.

## Tools I used
- **Excel**: pivot tables, slicers, charts, and dashboard design.
- **Data cleaning**: structured raw Spotify track dataset.
- **Visualization**: interactive dashboard for genre and feature analysis.

## What the dashboard shows
- Genre‑wise average popularity and share of high‑popularity tracks.
- Year‑wise trends in track popularity.
- Correlation between audio features and popularity.
- Filters to drill down into specific genres or years.

## Key takeaways
1. **Pop, Hip-Hop, and Latin** consistently lead in average popularity.  
2. **Danceability and energy** show a positive relationship with popularity.  
3. **Acousticness trends lower** for the most popular tracks.  
4. The **genre selector** helps test patterns within one segment.  

## How to try it
1. Download the Excel dashboard from the `dashboard/` folder.  
2. Open it in Microsoft Excel (2016 or later recommended).  
3. Use slicers and filters to explore popularity by genre, year, and audio features.
